Stream Timer

                

                  One clock = time left (counts down). Cap is always 12 hours total — not a second timer.
                  Start at 4:00:00; each sub/gift adds 9.6 min (50 from 4h → full 12h).
                  Go live → Start countdown or !subgoal start.
                

              

              
              

                
                
                
                
              

              

              

                
Chat commands

                

                  
                    
!subgoal / !subsAnyoneShow time left + sub count

                    
!subgoal startModsStart countdown from current time left

                    
!subgoal stopModsPause (time left freezes)

                    
!subgoal resetModsNew stream: 4:00 left + start counting

                    
!subgoal 5ModsAdd subs manually (+9.6 min each)

                    
!subgoal label 12 Hour StreamModsChange the label

                  
                

                
Kick subs / gift subs auto-add 9.6 minutes and start the countdown if it was paused. Cap is 12 hours.

              

            


            

              

                
Subathon

                

                  Classic countdown. A 300-sub drop at 5 min/sub opens at
                  25:00:00. Use Start at that time or
                  !subathon start 300. Extra Kick subs keep adding time.
                  OBS: /widgets/subathon.html?obs=1
                

              

              
              

                
                
                
                
                
              

              

                
                
                
                
                
              

              

                
                
                
              

              

              

                
Chat commands

                

                  
                    
!subathonAnyoneShow time left + sub count

                    
!subathon start / stopModsStart or pause the clock

                    
!subathon start 300ModsOpen the clock on 300 subs × min/sub (25:00 at 5 min)

                    
!subathon resetModsNew run from the start time

                    
!subathon 3ModsAdd 3 subs worth of time

                    
!subathon +10ModsAdd 10 minutes

                    
!subathon persub 5ModsMinutes added per sub

                    
!subathon label SUBATHONModsChange the overlay title

                  
                

                
Kick subs and gift subs add time automatically while this overlay is up.

OBS Browser Source URLs

              

              

                Add as a browser source with a transparent background. Use ?obs=1 for faster updates.
                Stream alerts sit at the top of the scene — same look as your rules banner.
                Chat box: Kick + Twitch. Optional ?max=30 message limit, ?compact=1 for a smaller box.
                Cam overlay: 1920×1080 browser source under your webcam (not on top).
              

              

                
                  
CommandWhoAction

                
                
                  
!request song nameAnyoneSearch Spotify and add song to queue

                  
!skipMods / streamerSkip current track

                  
!pauseMods / streamerPause or resume playback

                  
!replaysong or /replaysongMods / streamerRestart the current song from the beginning

                  
!vol 0-100Mods / streamerSet Spotify volume percent

                  
!lightsoffMods / streamerTurn all lights off and pause beat sync (music only)

                  
!lightsonMods / streamerResume beat sync with lights

                
              

              

                Light beat sync runs on this PC only — open http://127.0.0.1:3000 for the Lighting tab.
